# DataFarm Alerts API

This API is used to notify our clients of changes to their SensorData levels. Within this project, there is an ongoing effort to manage potential breaking changes. This is done via Github Actions and Workflows on this repository.

If you are interested in contributing, a good starting point would be to get familiar with the testing folder.

Any further questions are welcome at this [inbox](mailto:geraud@datafarm.co.za?subject=DataFarm%20Alerts%20Contributing).
